# Templates do Elementor

Exportações do Elementor Pro (`.json`), só pra versionar e reaproveitar. Não sobem por SFTP.

- Exportar: Templates → Templates Salvos → passar o mouse no template → Exportar.
- Importar em outro WordPress: Templates → Templates Salvos → Importar Templates.
- Nome do arquivo: `<tipo>-<nome>-<AAAA-MM-DD>.json` (ex.: `rodape-site-2026-10-09.json`).
